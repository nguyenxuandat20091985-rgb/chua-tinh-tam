# Chùa Tịnh Tâm – Tour 360°

Ứng dụng **VirtualTour360** (A-Frame) cho trải nghiệm đi chùa online.

## Chạy local

```bash
git clone https://github.com/nguyenxuandat20091985-rgb/chua-tinh-tam.git
cd chua-tinh-tam
npm install
npm run dev
```

Mở **http://localhost:3000**

## Component chính

- `src/components/VirtualTour360.tsx` – viewer 360° (ảnh hoặc video)
- `src/App.tsx` – trang demo

## Thay ảnh/video chùa

Sửa `panoramaUrl` trong `src/App.tsx` thành link ảnh equirectangular hoặc video 360° của anh.
